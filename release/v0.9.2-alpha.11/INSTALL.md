# Kurulum / Installation — v0.9.2 Alpha 11

## Türkçe

Bu sürüm, XenForo 2.3+ normal Admin CP archive kurulumu için hazırlanmış Alpha güncellemesidir.

### Güncelleme

1. `Warext-GitHub-Sync-v0.9.2-Alpha11-install.zip` dosyasını indirin.
2. XenForo Admin CP > Add-ons > Install/upgrade from archive alanını açın.
3. ZIP dosyasını doğrudan yükleyin ve yükseltmeyi tamamlayın.
4. Mevcut v0.9.0 Alpha 9 veya v0.9.1 Alpha 10 kurulumu varsa kaldırmayın; paket upgrade olarak kurulmalıdır.

Bu sürüm `admin:wgh_actions`, `admin:wgh_health` ve `admin:wgh_xfrm` template'lerindeki geçersiz `<xf:submit>` tag'lerini XenForo'nun desteklediği submit button yapısına çevirir.

Kurulumdan sonra Admin CP > Tools > Warext GitHub Sync alanını kontrol edin.

---

## English

This Alpha update is packaged for normal XenForo 2.3+ Admin CP archive installation.

### Upgrade

1. Download `Warext-GitHub-Sync-v0.9.2-Alpha11-install.zip`.
2. Open XenForo Admin CP > Add-ons > Install/upgrade from archive.
3. Upload the ZIP directly and finish the upgrade.
4. Do not uninstall an existing v0.9.0 Alpha 9 or v0.9.1 Alpha 10 installation; install this package as an upgrade.

This release replaces invalid `<xf:submit>` tags in `admin:wgh_actions`, `admin:wgh_health` and `admin:wgh_xfrm` with XenForo-supported submit buttons.

After upgrading, check Admin CP > Tools > Warext GitHub Sync.
