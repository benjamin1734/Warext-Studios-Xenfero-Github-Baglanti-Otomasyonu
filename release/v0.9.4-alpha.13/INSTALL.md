# Warext GitHub Sync v0.9.4 Alpha 13

## Türkçe

### Kurulum / Güncelleme
1. XenForo Admin CP > **Add-ons > Install/upgrade from archive** bölümünü açın.
2. `Warext-GitHub-Sync-v0.9.4-Alpha13-install.zip` dosyasını yükleyin.
3. Mevcut eski Alpha sürümünü kaldırmayın; paket yükseltme olarak kurulabilir.
4. Kurulumdan sonra Admin CP sol menüsünde bağımsız **Warext GitHub Sync** kategorisi görünmelidir.
5. Super admin olmayan yöneticilere `wghManage` admin yetkisi verilmelidir.

Kategori altında Dashboard, Connections, Repositories, Mappings, Templates, Actions, PR Tools, XFRM, Health, User Mappings, Conflicts, Webhook Logs ve Diagnostics bağlantıları bulunur.

> Alpha/test sürümüdür.

## English

### Install / Upgrade
1. Open XenForo Admin CP > **Add-ons > Install/upgrade from archive**.
2. Upload `Warext-GitHub-Sync-v0.9.4-Alpha13-install.zip`.
3. Do not uninstall an older Alpha build first; this package can be installed as an upgrade.
4. After installation, a dedicated **Warext GitHub Sync** collapsible category should appear in the Admin CP sidebar.
5. Non-super administrators must be granted the `wghManage` administrator permission.

The category contains Dashboard, Connections, Repositories, Mappings, Templates, Actions, PR Tools, XFRM, Health, User Mappings, Conflicts, Webhook Logs and Diagnostics.

> This is an Alpha/testing build.
