# Warext GitHub Sync v1.0.1 — Kurulum / Installation

## Türkçe

1. `Warext-GitHub-Sync-v1.0.1-install.zip` dosyasını indirin.
2. XenForo Admin CP → Add-ons → **Install/upgrade from archive** bölümünden ZIP'i kurun veya mevcut kurulumu yükseltin.
3. Admin CP'de **Warext GitHub Sync** alanından GitHub App bağlantısını ve gerekli izinleri yapılandırın.
4. Türkçe arayüz için ZIP içindeki `languages/Turkish.xml` dosyasını Türkçe XenForo diline (veya alt dile) içe aktarın.
5. İngilizce paket istenirse `languages/English.xml` dosyasını ilgili İngilizce dile içe aktarın.

Mevcut v1.0.0 kurulumu doğrudan v1.0.1'e yükseltilebilir. Önce kaldırmayın.

## English

1. Download `Warext-GitHub-Sync-v1.0.1-install.zip`.
2. Install or upgrade it through XenForo Admin CP → Add-ons → **Install/upgrade from archive**.
3. Configure the GitHub App connection and required permissions under **Warext GitHub Sync**.
4. Import `languages/English.xml` into the matching English XenForo language (or child language).
5. For Turkish, import `languages/Turkish.xml` into the matching Turkish language.

Existing v1.0.0 installations can be upgraded directly to v1.0.1. Do not uninstall first.
