# Kurulum / Installation — v0.9.3 Alpha 12

## Türkçe

Bu sürüm, XenForo Admin CP template derleyicisinde görülen `admin:wgh_mappings` syntax hatasını giderir.

### Kurulum / Güncelleme
1. `Warext-GitHub-Sync-v0.9.3-Alpha12-install.zip` dosyasını indirin.
2. XenForo Admin CP → Add-ons → Install/upgrade from archive alanından mevcut eklentinin üzerine yükleyin.
3. Kurulum tamamlandıktan sonra Admin CP → Tools → Warext GitHub Sync alanını açın.

v0.9.0 Alpha 9 kurulu görünse bile kaldırmayın; doğrudan upgrade yapın.

---

## English

This release fixes the XenForo Admin CP template syntax error in `admin:wgh_mappings`.

### Install / Upgrade
1. Download `Warext-GitHub-Sync-v0.9.3-Alpha12-install.zip`.
2. Upload it through XenForo Admin CP → Add-ons → Install/upgrade from archive.
3. After installation, open Admin CP → Tools → Warext GitHub Sync.

Do not uninstall the existing v0.9.0 Alpha 9 entry; upgrade it in place.
