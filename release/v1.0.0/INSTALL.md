# Warext GitHub Sync v1.0.0 — Kurulum / Installation

## Türkçe

1. `Warext-GitHub-Sync-v1.0.0-install.zip` dosyasını indirin.
2. XenForo Admin CP → Add-ons → **Install/upgrade from archive** bölümüne gidin.
3. ZIP dosyasını seçip kurulumu veya güncellemeyi başlatın.
4. Kurulumdan sonra Admin CP sol menüsünde **Warext GitHub Sync** kategorisini açın.
5. GitHub App bağlantısını ve gerekli izinleri yapılandırın.

Mevcut `v0.9.4 Alpha 13` kurulumu doğrudan yükseltilebilir. Önce kaldırmayın.

## English

1. Download `Warext-GitHub-Sync-v1.0.0-install.zip`.
2. Open XenForo Admin CP → Add-ons → **Install/upgrade from archive**.
3. Select the ZIP and start the installation or upgrade.
4. After installation, open the dedicated **Warext GitHub Sync** category in the Admin CP sidebar.
5. Configure the GitHub App connection and required permissions.

Existing `v0.9.4 Alpha 13` installations can be upgraded directly. Do not uninstall first.
